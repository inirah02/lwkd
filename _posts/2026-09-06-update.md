## Other Merges

* kubectl: [documentation for the `--restart` flag values on `kubectl run`](https://github.com/kubernetes/kubernetes/pull/141728) has been improved.
* Adds a [`+k8s:immutable` tag to validation-gen](https://github.com/kubernetes/kubernetes/pull/141727) so declarative validation can express immutable field semantics.
* kube-scheduler adds a [`PostBind` extension point](https://github.com/kubernetes/kubernetes/pull/141715) under [KEP-6021](https://github.com/kubernetes/enhancements/tree/master/keps/sig-scheduling/6021-postbind-extension-point) for plugins that run after a Pod has been bound to a Node.
* The [cluster-autoscaler now integrates with the Cluster API](https://github.com/kubernetes/kubernetes/pull/141714) directly for machine-lifecycle operations rather than via a shim.
* kubectl: adds [`--warnings-as-errors` support to `kubectl apply` and `kubectl apply --dry-run=server`](https://github.com/kubernetes/kubernetes/pull/141709), so CI pipelines can fail on server-side warning conditions.
* kubelet: [fixes swap accounting for pods with cgroups v2 `memory.swap.max`](https://github.com/kubernetes/kubernetes/pull/141701) so allocated swap is now correctly reflected in Pod status.
* `kube-controller-manager` adds a [new `_total` counter for controller reconciliation errors](https://github.com/kubernetes/kubernetes/pull/141696).
* kubelet: [`PodSandboxConfig.resource_claims` is now propagated to the runtime](https://github.com/kubernetes/kubernetes/pull/141691) for DRA-enabled pods.
* validation-gen: [eliminates zero-value comparison in `+k8s:required` codegen](https://github.com/kubernetes/kubernetes/pull/141689) so pointer-typed required fields don't incorrectly reject zero values.
* kube-proxy nftables: [fixes cross-namespace hairpin traffic for NodePort services](https://github.com/kubernetes/kubernetes/pull/141684).
* DRA: the [scheduler filter now checks device tainted state](https://github.com/kubernetes/kubernetes/pull/141680) under KEP-5055 (DRA Device Taints and Tolerations), rejecting pods that don't tolerate the taint.
* Adds [DRA Extended Resource support to `scheduler_perf`](https://github.com/kubernetes/kubernetes/pull/141678) so DRA benchmarks can measure Extended Resource pathways.
* validation-gen: [fixes ProtocolIsProto codegen for the slice-to-pointer path](https://github.com/kubernetes/kubernetes/pull/141673).
* apiserver: [structured logging trace context is now propagated through request paths](https://github.com/kubernetes/kubernetes/pull/141667).
* DRA: introduces a [prioritized-list ordering algorithm for `PrioritizedList`](https://github.com/kubernetes/kubernetes/pull/141664) requests.
* scheduler: attaches a [`SchedulingResult` to Pod events](https://github.com/kubernetes/kubernetes/pull/141663) so future scheduling events can reference the prior decision.
* kubelet DRA: [fixes a bug where shared claims were dropped across kubelet restarts](https://github.com/kubernetes/kubernetes/pull/141557).
* Fixes an [apiserver watch cache metric bug](https://github.com/kubernetes/kubernetes/pull/141333) where `events_dispatched_total` was incremented for undispatched bookmarks.
* [Renames `endpoint_slice_controller_changes` to `endpoint_slice_controller_changes_total`](https://github.com/kubernetes/kubernetes/pull/140447) to add the conventional `_total` suffix; the old name is retained temporarily for backward compatibility.
* Clarifies that the [`/flagz` endpoint reflects flag layer, not effective config](https://github.com/kubernetes/kubernetes/pull/140233).
